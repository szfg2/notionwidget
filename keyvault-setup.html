Key vault setup

Locks the keys saved in this browser with a random code, so the tools can unlock them on a work computer. Open this page the way you normally open the tools on your laptop (e.g. through RESTools), so it can see your saved keys. Nothing leaves this page except the file you download.

1. Choose what to lock

No keys found in this browser. Open this page from the same address you use for the tools.

2. Create the code and locked file

Each run makes a new code and replaces the old one.

Save this code in your phone's password manager now. It is not stored anywhere else. If you lose it, run this page again.

3. Check the code you saved

Type it in from your phone to make sure it was saved correctly.

4. Put it live

  1. Move keyvault.data.js into the notionwidget repo folder, replacing any old copy.
  2. Commit and push. GitHub Pages updates in about a minute, widgets.szfg2.tech within 5.
  3. On a work computer, open any tool and enter the code when asked.

Git keeps old versions of the file. If a code is ever seen by someone else, making a new code is not enough: replace the API keys themselves with each provider.
